# Official package index

This page reflects the package names currently declared in metapackage
dependencies. CI treats those dependency declarations as the official package set.

## Metapackages

- `calibrated-explanations-plugins`: curated official set
- `calibrated-explanations-calibration`: official calibration family
- `calibrated-explanations-explanation`: official explanation family
- `calibrated-explanations-visualization`: official visualization family

## Plugins

- `calibrated-explanations-calibration-example`: example calibration plugin
- `calibrated-explanations-explanation-alternative-example`: example alternative explanation plugin
- `calibrated-explanations-explanation-factual-example`: example factual explanation plugin
- `calibrated-explanations-explanation-factual-lime`: factual LIME explanation plugin
- `calibrated-explanations-explanation-factual-shap`: factual SHAP explanation plugin
- `calibrated-explanations-visualization-dashboard`: dashboard visualization plugin
- `calibrated-explanations-visualization-example`: example visualization plugin
- `calibrated-explanations-visualization-factual-shap`: factual SHAP visualization plugin
- `calibrated-explanations-visualization-plotly`: Plotly visualization plugin layouts
